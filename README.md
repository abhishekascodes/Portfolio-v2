## Local Development

### Prerequisites

- Node.js 18+
- npm or pnpm

### Getting Started

```bash
# Clone the repository
git clone https://github.com/abhishekascodes/Portfolio-v2.git
cd Portfolio-v2

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Compile and build production bundle
npm run build

# Preview production build locally
npm run preview
```
